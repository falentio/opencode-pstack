### Pause safely

**You own a clean stop. Leave a checkpoint a cold-start agent can resume from.** Use this playbook only for an explicit pause request, including "pause safely", "I need to go offline", "restart Cursor", or "board my flight", and when context is about to compact or summarize. Treat "keep going", "going to bed, keep going", and "don't stop" as continue instructions. Do not pause for those requests. Those mean continue, and Autonomous run already checkpoints per iteration.

**Pause gate.** The request is an explicit pause request or context is about to compact or summarize, and no continue instruction applies.

1. **Stop at a safe boundary.** Finish the current atomic step or back out of it. Never stop mid-edit in a known-broken state. Start nothing new, and cancel any nested subagents. **Completion check.** The current atomic step is finished or backed out, the work is not left mid-edit in a known-broken state, no new work has started, and no nested subagents remain.
2. **Keep the pause reversible.** Do not cross an irreversible line to pause. Create no PR and make no push unless you already had one out. **Completion check.** No new PR or push was created for the pause, and any exception already existed before these steps began.
3. **Make the work durable.** Commit uncommitted edits as one clear `wip:` commit on the current branch so nothing is lost. If the tree is broken, say so in the commit body in one line. **Completion check.** If uncommitted edits existed, they are in one `wip:` commit on the current branch, and a broken tree is named in one commit-body line when applicable.
4. **Write the resume note off-context.** Capture intent, what you were doing, progress, what is verified, current state, next steps, key files, and gotchas. For the compaction trigger, write it to a file like `/tmp/<slug>-resume.md` because the in-context plan will not survive summarization. If a show-me-your-work trail exists, point at it instead of duplicating it. **Completion check.** The resume note contains every listed field, the compaction note is written outside the context at the required path pattern, and an existing show-me-your-work trail is referenced instead of duplicated.

**Reply.** Include where you are in the loop, what is on disk versus still in your head with paths and no diff dumps, the commits you made and whether the tree is clean, and the first action on resume. This is a pause, not a final report. Resume is the [Session pickup playbook](session-pickup.md) reading this note.
